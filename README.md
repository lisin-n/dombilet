# DomBilet — интерактивные схемы

Статическая версия двух схем в текущем оформлении DomBilet:

- [Yas Marina Circuit](https://lisin-n.github.io/dombilet/yas-marina/)
- [Ozon Арена · Краснодар](https://lisin-n.github.io/dombilet/krasnodar/)

Главная страница открывает Yas Marina. На телефоне схемы сохраняют исходную ориентацию. Краснодар расположен по центру карты. Выбранные билеты отображаются в нижней панели исходной страницы.

## Файлы

`site/yas-marina/` и `site/krasnodar/` — страницы площадок. Общий блок схем, окна и выбор билетов находятся в `site/schemes/`; данные — в `data.js`, оформление — в `styles.css`. `site/assets/` содержит локальные ресурсы исходной страницы, включая Manrope с кириллицей.

У Краснодара подключены 46 исходных схем с 35 356 креслами. SVG отдельного сектора загружается при выборе мест. Для видов с сектора используется по одному выбранному фото; неподтверждённые виды не подменяются соседними.

Все 36 предложений Yas Marina доступны на схеме и в списке. Дополнительные зоны берутся из последней SVG и привязываются к соответствующим трибунам на иллюстрации. Команда `python3 scripts/build-yas-marina-zones.py` обновляет карту и проверяет совпадение с каталогом.

Цены и наличие демонстрационные. Оформление открывает локальный итог; для реальной корзины предусмотрен `window.DomBiletScheme.onContinue(payload)`. Отправка запросов на покупку отключена. Остальная страница сохранена как контекст исходного макета.

## GitHub Pages

Публикация происходит автоматически из папки `site` при обновлении ветки `main` через GitHub Actions. В Settings → Pages источник должен быть **GitHub Actions**. Сборка приложения и сервер не нужны; все пути учитывают префикс `/dombilet/`.

## Локальная проверка

Из корня репозитория:

```sh
python3 -m http.server 5187
```

Открыть `http://127.0.0.1:5187/site/yas-marina/` или `/site/krasnodar/`.

## Источники

Оболочка страницы: [DomBilet](https://dombilet.ru/). Схемы секторов, кресел и фотографии — материалы проекта. Окружение Ozon Арены — схематичный рисунок по расположению ориентиров на [генплане gmp](https://www.gmp.de/en/projects/670/park-and-fc-krasnodar-stadium).
